# Disabled untrusted Books scoped setup and role UX

Task 57 is a dedicated **group-only scoped editor** profile. The product choice is reads and
writes for Books, not reader-only and not a personal account connection. The device is untrusted;
only an `absk_` machine or `absi_` scoped installation secret is accepted. Account/personal-device
tokens fail before network requests. No account-login/password interface, whole-vault membership
parser, owner publisher, script/code approval or second connection exists in this controller.

`BooxBooksSetup` requires an empty dedicated local vault, no retained personal/scoped identity,
exact issuer/vault/grant/principal and an owner-selected stable Books root ID/version. Label or
basename equality is not that proof. Current server group/editor authority and independently
verified native transport are mandatory. A reader ceiling, preparing/revoked view or unsupported
transport is an actionable hold, not a local upgrade or full-vault fallback.

Keychain proofs bind the whole scoped descriptor/token independently of local metadata.
Descriptor ownership is durable before first ledger allocation. Reopening a missing/corrupt
bound ledger holds recovery without login/re-enrolment/reinitialization. Setup uses only complete
authorized server manifests; known-but-not-materialized/size-omitted content is its own state,
not a remote delete or an implicit local create. Downloaded bytes remain after revoke.

Editor permission is scoped: authorized note bodies and proven own native content may be edited;
new native notes/images still need the existing approved-root/intrinsic-sponsor/own-upload and
cross-grant checks. Imported owner assets are read-only; choose a genuinely new native copy at a
free path. Existing group fields, owner publication, script execution and personal setup remain
refused. Server authority—not the informational UI matrix—decides every write.

The readonly disabled modal explains editor status, known/materialized/omitted counts,
preparing/offline/revoked/recovery/unsupported transport and the credential boundary. It can be
previewed from the connect card without any setup effect. Protected native ledger, current-root,
verified Android transport and scoped manifest host adapters remain mandatory and unwired while
activation is false. The physical iPhone/desktop UI inspection is NOT an Android/Boox/e-ink or
native Books synchronization acceptance claim.
