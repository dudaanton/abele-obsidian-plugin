exact identities/versions/SHA and a current generation. It does not parse whole-vault frontmatter,
resolve private basenames or infer an anchor from a recipient-created note. An opaque review ID,

relation/anchor approval; an explicit separate action rechecks certification/source/target/token

inputs destroys credentials/review, and late replies cannot replace another confirmation.

exact reviewed group payloads and disjoint owner-personal device proof. Real disposable HTTP

and worker-preview host ports remain required; no nonexistent preview route is fabricated.

not automatic body-link publication. Bounded targets/sponsors/audiences are shown together;

before the first mutation. Per-audience exact requests/intent IDs are checksum-bound and durable
before send. Multiple entries reconcile the current CAS only before their first send; lost
responses reopen/retry the same request without a new prompt or whole-list replacement. A
replacement, changed sponsor, revoked/preparing view or withdrawal holds instead of resurrecting
old permission. Missing journal evidence is recovery, not an inferred batch.
